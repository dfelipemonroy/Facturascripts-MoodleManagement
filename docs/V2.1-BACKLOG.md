## Change policy

- Entries move **out** of this file when they land in a v2.x
  release, not into it — avoids "ghost" items that hang on.
- New discoveries during v2.1 development append here with a
  fresh `DISCOVERED-NN` tag, where NN continues past D-07
  (next available: D-08 — reserved for this file).
- v2.0 ships shipping **with** this file version-controlled so
  the v2.1 scope is visible to every contributor on day 1.
