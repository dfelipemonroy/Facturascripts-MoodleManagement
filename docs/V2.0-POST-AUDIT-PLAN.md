## Notas de proceso

- **Commits**: Conventional Commits + audit ref. Formato: `<type>(v2.0): <subject> [#AUDIT-FX.Y-SEC-NN]`.
- **Tests nuevos obligatorios** para cada fix de severidad HIGH o superior.
- **Regresión cero**: cada fase arranca de tests verdes y cierra con tests verdes. Si una fase introduce regresión, se revierte o se bloquea hasta fix.
- **Dead code scope creep**: cada vez que se toque dead code (Retry/Breaker en BE-02, facades en ARCH-01), aprovechar para integrar en lugar de eliminar. Si no se puede integrar en v2.0, eliminar con justificación en CHANGELOG.
- **Orden preferente dentro de fase**: primero los IDs con menor superficie (changelog simple, un archivo), después los transversales.
